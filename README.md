## => Sobre o Projeto
Este projeto foi desenvolvido pensando em unir a **lógica de programação** com a **análise de processos e negócios**. 
A ferramenta simula o mapeamento de etapas de um fluxo de trabalho (como o atendimento ao cliente ou a gestão de pedidos), permitindo registar o tempo estimado versus o tempo real gasto em cada fase para identificar visualmente onde ocorrem os **gargalos operacionais**.

---

## => Funcionalidades
* **Registo de Etapas:** Permite inserir o nome das fases de um processo.
* **Cálculo de Desvios:** Compara o tempo planeado com o tempo real de execução.
* **Identificação de Gargalos:** Aponta qual etapa consumiu mais tempo ou gerou atrasos no fluxo.
* **Saída Simples:** Exibe os resultados organizados diretamente no terminal.

---

## =>  Tecnologias Utilizadas
* **Python 3:** Utilizado para a lógica principal, estruturas de controle (condicionais e repetição), manipulação de listas/dicionários e funções.
